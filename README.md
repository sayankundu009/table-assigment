# Employee Directory Assignment

## Overview
This assignment involves building an interactive Employee Directory web application with filtering and search capabilities. The application displays employee data in a table format with various filtering options.

## Data Structure

### Employees
The application includes 10 sample employees with the following fields:
- **ID**: Unique identifier
- **Name**: Employee full name
- **Department**: Engineering, Design, Marketing, HR, Finance, Sales, Customer Success
- **Role**: Specific job title
- **Email**: Contact email
- **Phone**: Contact number
- **Projects**: Array of project IDs
- **Salary**: Annual salary

### Projects
6 sample projects with:
- **ID**: Unique project identifier
- **Name**: Project name
- **Start Date**: Project start date
- **Status**: Completed, In Progress, Not Started
